About this Website

Charcoal is a web-based markdown note-taking application developed as a student project for educational and demonstration purposes. It lets users write notes in the browser, manage them in a sidebar, export them as markdown files, use guest mode, or register an account.

The project was developed as part of an academic portfolio for the course Project Java and Web Development (DLBCSPJWD01) at IU International University of Applied Sciences.

Charcoal is not an official website or service of IU International University of Applied Sciences and is not operated on behalf of the university.
